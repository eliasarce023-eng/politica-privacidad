Extensión de Chrome

Política de Privacidad

Herramientas Asesor · Última actualización: 3 de agosto de 2026

¿Qué hace esta extensión?

Herramientas Asesor es una extensión de uso interno para asesores. Permite registrar quejas y reclamos mediante un formulario guiado, guardar accesos rápidos, llevar un registro de ventas, tomar notas y compartir recordatorios ("papelitos") entre compañeros de equipo, con la información sincronizada entre los distintos computadores de cada usuario.

Datos que sí recopilamos

Para que la extensión funcione y tu información te acompañe entre computadores, guardamos:

  • Usuario y contraseña, para identificarte al iniciar sesión. La contraseña es gestionada de forma segura por Firebase Authentication (Google) y nunca se guarda en texto plano ni es visible para nosotros.
  • El contenido que tú mismo escribes: formularios de quejas, accesos guardados, notas, registros de ventas (por ejemplo, un ID de venta o un comentario) y papelitos de recordatorio.
  • Papelitos compartidos: si decides compartir una nota con otro usuario de la extensión, el texto y tu nombre de usuario se guardan para que esa persona pueda verla.

Datos que NO recopilamos

Esta extensión no recopila ni almacena:

  • Información financiera o de pago (tarjetas, montos bancarios, etc.)
  • Ubicación geográfica
  • Historial de navegación o actividad fuera de la extensión
  • Información de salud
No se recopilan datos financieros ni de ubicación

Dónde se almacenan tus datos

La información se guarda de forma segura en Firebase (Google Cloud), que actúa únicamente como infraestructura de almacenamiento para esta extensión. Firebase no tiene acceso a usar tus datos con fines propios.

Compartición de datos con terceros

Esta extensión no vende, comparte ni transfiere tu información a terceros con fines publicitarios, comerciales ni de ningún otro tipo, bajo ninguna circunstancia.

Tus datos nunca se venden ni se comparten

Cómo eliminar tus datos

Puedes eliminar tu cuenta y todos los datos asociados a ella en cualquier momento desde el botón "Eliminar usuario" dentro de la extensión, confirmando con tu contraseña. La eliminación es permanente e inmediata.

Cambios en esta política

Si en el futuro se realizan cambios en la forma en que se manejan los datos, esta política será actualizada con la nueva fecha de vigencia. Te recomendamos revisarla periódicamente para mantenerte informado.
